## 设计与验收

- `chat [--prd 文件]` 开启终端交互；退出后再次进入可恢复 PRD、讨论和 DS 会话。
- GPT 对话记录由 SQLite 持久化，每次只读 Codex 调用重建上下文，不依赖隐式的最近 Codex 会话。
- 普通文字只讨论，不自动触发执行。`/plan` 生成计划；`/execute` 后台执行 DS；执行期间可继续与 GPT 讨论。
- 异步 stdin 和后台任务允许 `/status`、`/pause` 随时响应。暂停实际是终止当前进程组，保留代码、日志和会话，不声称工具调用可以无损挂起。
- 讨论、PRD 更新、暂停和重启均保留当前计划。`/resume` 或暂停后的 `/execute` 恢复原计划和 DS 会话，不调用 GPT 重新规划。新 `/plan` 通过校验且 ready 后才原子替换当前计划；规划失败、blocked 或取消均保留原计划。
- `/wait` 等待当前 GPT/DS 工作结束；`/exit` 或 EOF 取消工作并保存状态。
- 核心代码中文注释；README 按四个部分重写。内部恢复与开发细节移至 docs，不挤入首页。
