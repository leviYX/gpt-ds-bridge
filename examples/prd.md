# 示例 PRD：健康检查接口

## 背景

现有后端项目需要一个健康检查端点。请先识别仓库当前使用的语言、框架、路由约定和测试方式，再采用既有风格实现。

## 需求

- 增加 `GET /health`，成功响应 HTTP 200 和 JSON `{"status":"ok"}`。
- 接口不依赖数据库或外部服务，不暴露配置、凭据或内部版本信息。
- 保持现有接口行为和项目依赖不变。
- 如已有同类端点，先核对其行为，避免重复实现。

## 验收

- 可以验证请求方法、路由、状态码和响应体。
- 运行与此次修改相关的现有测试；如仓库没有测试基础设施，说明实际验证方式和局限。
- 最终报告列出修改文件、验证命令、结果和未完成事项。
- 不执行 Git 提交、推送或部署。

## 范围

仅修改业务工作区。如果仓库并非后端项目，或不存在可确定的 HTTP 服务入口，请先提问，不要另建一套无关应用。
